# OXEN Power Guard

> 합주실 메인 앰프와 믹서의 안전한 전원 관리를 위한 안내 프로그램

OXEN 합주실에서 사용하는 메인 앰프와 믹서의 전원 조작 순서를 안내하는 프로그램이다.  
장비를 켜거나 끌 때 정해진 순서와 대기 시간을 지킬 수 있도록 단계별 안내와 타이머, 그리고 화면 이탈 방지 기능을 제공한다. 이를 통해 전원 조작 과정에서 발생할 수 있는 실수를 줄이고, 누구나 동일한 절차에 따라 장비를 관리할 수 있도록 돕는다.

## 프로그램 소개

합주실의 메인 앰프와 믹서는 전원을 켜고 끄는 순서가 중요하다.

특히 믹서와 앰프의 전원을 조작하는 과정에서 순서를 지키지 않거나 필요한 대기 시간을 놓치면 스피커에서 큰 팝 노이즈가 발생할 수 있다.

OXEN Power Guard는 이러한 상황을 예방하기 위해 제작되었다.

프로그램 실행 시 화면 정중앙 최상단에 안내 창이 고정되며, 전원 켜기 또는 끄기를 선택하면 정해진 순서에 따라 현재 해야 할 작업을 안내한다. 사용자는 실제 장비를 조작한 뒤 완료 버튼을 누르면 되고, 대기 시간이 필요한 단계에서는 30초 타이머가 자동으로 작동한다. 전원 켜기를 완료하면 합주 중 X Air 화면을 가리지 않도록 우측 상단 미니 바로 축소할 수 있다.

**주요 기능**

- 전원 켜기 및 끄기 단계별 절차 안내
- 화면 정중앙 최상단 고정 및 타이틀바 제거를 통한 절차 이탈 방지
- 전원 켜기 완료 후 합주 중 우측 상단 미니 바(`● 합주 중 | 전원 끄기`) 축소 모드
- 30초 대기 타이머 및 종료 시 시각·청각적 알림
- 순서에 맞지 않는 단계 진행 방지
- 전원 종료 절차 미완료 상태에서 프로그램 또는 OS 종료 시도 시 차단 및 경고

## 프로젝트 구조

```text
oxen-power-guard/
├── src/
│   ├── main.py              # 프로그램 실행 진입점
│   ├── guard_controller.py  # 전원 절차 상태 및 타이머 제어 로직
│   ├── guard_view.py        # Tkinter UI 렌더링 및 창 제어
│   ├── ui_widgets.py        # 공통 테마 상수 및 OS 호환 커스텀 버튼
│   ├── power_sequence.py    # 전원 켜기/끄기 단계 데이터
│   └── notifications.py     # 운영체제별 완료 알림음 재생
│
└── README.md
```

## 실행 환경

| 항목 | 내용 |
| --- | --- |
| 주 운영체제 | Windows |
| 개발 운영체제 | macOS |
| 지원 대상 | Windows / macOS |
| 실행 방식 | 터미널에서 실행 (`python3 src/main.py`) |

Windows 환경을 주 사용 환경으로 개발한다. 다만 macOS에서도 버튼 색상 및 창 동작이 동일하게 유지되도록 크로스플랫폼 위젯으로 구성했다.

별도의 서버나 데이터베이스 없이 표준 라이브러리(`tkinter`)만으로 실행할 수 있다.

## 사용 방법

프로그램을 실행하면 화면 정중앙에 전원 켜기와 전원 끄기 두 가지 메뉴가 표시된다.

원하는 작업을 선택하면 해당 절차가 시작된다. 각 단계에는 수행해야 할 작업과 완료 버튼이 표시되며, 안내에 따라 실제 장비를 조작한 뒤 버튼을 누르면 다음 단계로 넘어간다.

### 1. 전원 켜기

다음 순서에 따라 진행한다.

1. 믹서 오른쪽 벽 스위치 ON
2. 30초 대기
3. 메인 앰프 ON
4. 컴퓨터에서 X Air 실행
5. Connect 클릭 후 MIXER to PC 선택
6. 필요한 채널과 Main의 하단 Mute 해제
7. 완료 화면에서 **합주 중이에요** 버튼을 눌러 우측 상단 미니 바로 축소

**주의사항**

* 믹서를 켠 직후 앰프를 켜지 않는다.
* 믹서 전원을 켠 후 반드시 30초를 기다린다.
* X Air 연결이 정상적으로 이루어지지 않으면 우측 상단 Setup에서 믹서 연결 상태를 확인한다.

### 2. 전원 끄기

합주가 끝나면 우측 상단 미니 바의 **전원 끄기** 버튼을 눌러 창을 복귀시킨 뒤 다음 순서에 따라 진행한다.

1. X Air 연결 상태 확인
2. 전체 채널 및 Main Mute
3. 메인 앰프 OFF
4. 30초 대기
5. 앰프의 빨간 표시등이 꺼졌는지 확인
6. 믹서 전원 OFF

**주의사항**

* 앰프를 끄기 전에 반드시 전체 채널과 Main을 Mute한다.
* 앰프를 끈 후 30초가 지나기 전에는 믹서 전원을 끄지 않는다.
* 앰프의 빨간 표시등이 꺼졌는지 직접 확인한다.
* 합주가 끝나면 다음 합주팀이 있더라도 장비를 반드시 끄고 퇴실한다.

## 모니터 스피커 안내

모니터 스피커는 연주자가 자신의 소리를 더 잘 들을 수 있도록 사용하는 별도 장비다.

채널 구성은 다음과 같다.

| 채널 | 연결 장비 |
| --- | --- |
| 1번 | 퍼스트 건반 |
| 2번 | 세컨 건반 |
| 3번 | 메인 마이크 |

모니터 앰프는 후면 중앙에 있는 Power 버튼으로 직접 켜고 끈다.

음량을 조절하려면 각 채널의 빨간색 Level 노브를 사용한다. 흰색 노브는 임의로 조작하지 않는다.

모니터 스피커는 메인 앰프와 별도로 조작하며, 현재 프로그램의 전원 관리 대상에는 포함되지 않는다.

## 프로그램 사용 시 유의사항

1. 프로그램의 안내에 따라 순서대로 장비를 조작한다.
2. 장비를 실제로 조작한 후 완료 버튼을 누른다.
3. 타이머가 작동하는 동안에는 임의로 다음 단계로 넘어가지 않는다.
4. 프로그램이 장비의 실제 전원 상태를 자동으로 확인하는 것은 아니다. 표시등이나 연결 상태 등은 사용자가 직접 확인해야 한다.
5. 전원 끄기 절차를 완료하기 전까지는 일반 창 닫기 및 시스템 종료 시도가 차단되며 경고 창이 표시된다. (관리자 비상 종료 단축키: `Ctrl + Shift + Q`)
6. 장비의 지정된 FX, EQ 및 기타 밸런스 값은 임의로 변경하지 않는다.

프로그램은 장비를 직접 제어하는 것이 아니라 올바른 조작 순서를 안내하는 보조 도구다. 실제 장비의 상태를 확인하고 조작하는 책임은 사용자에게 있다.

```bash
python3 src/main.py

```
